# SIBOOR Trident 350 AWD — иллюстрированная инструкция R3

Откройте [индекс](index.html) через GitHub Pages. Он собирает две части исходного HTML в браузере и показывает иллюстрированную пошаговую инструкцию; в ней встроены 205 страниц оригинального руководства.

В папке сохранены PDF R3, текущее состояние проекта, журнал сборки и фото. Большие файлы разделены на бинарные части из-за лимита запроса при загрузке в GitHub:

- `parts/manual-html-01.bin` и `parts/manual-html-02.bin` — исходный HTML R3; индекс собирает их для просмотра.
- `parts/official-source-pdf-01.bin`–`04.bin` — исходный официальный PDF SIBOOR от 2024-12-31; кнопка на индексе собирает и скачивает единый PDF.
- `SIBOOR_TRIDENT_350_AWD_JUNE_2024_R3.pdf` — PDF R3.
- `PRINTER_STATE.yaml`, `ASSEMBLY_LOG.md` и `evidence/` — состояние, журнал и фото.

Для индекса и сборки PDF в браузере должен быть включён JavaScript.
