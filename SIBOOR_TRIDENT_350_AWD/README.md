# SIBOOR Trident 350 AWD — иллюстрированная инструкция R3

Откройте [`index.html`](index.html) через GitHub Pages: он собирает две части HTML в браузере и показывает иллюстрированную пошаговую инструкцию (205 страниц исходного руководства встроены рядом с шагами).

В каталоге сохранены исходный PDF R3, фото и состояние проекта. Официальный PDF SIBOOR от 2024-12-31 разделён на четыре бинарные части из-за ограничений загрузки; кнопка «Скачать оригинальный PDF SIBOOR» на странице `index.html` собирает части и скачивает единый PDF.

Части HTML и исходного PDF хранятся в `parts/`. Для показа HTML и скачивания PDF нужен браузер с включённым JavaScript.

## Состав

- `SIBOOR_TRIDENT_350_AWD_JUNE_2024_R3.html` — исходная собранная HTML-инструкция (размещена как две части в `parts/`)
- `SIBOOR_TRIDENT_350_AWD_JUNE_2024_R3.pdf` — PDF R3
- `source/` — исходный официальный PDF SIBOOR (размещён как четыре части в `parts/`)
- `PRINTER_STATE.yaml` и `ASSEMBLY_LOG.md` — текущие записи проекта
- `evidence/` — фото содержимого
