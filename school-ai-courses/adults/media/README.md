# Видео взрослого направления

Папка для коротких видео первого экрана раздела «ИИ для дела».

Загрузите два MP4 с **точными именами**:

- `hero-teachers.mp4` — педагогическая практика
- `hero-life.mp4` — повседневные задачи

HTML-страница `/school-ai-courses/adults/` уже ссылается на эти имена. До появления MP4 показываются прежние графические сцены.
