Выберите задачу — найдите инструмент

Сначала сформулируйте роль, задачу, результат и допустимый материал. Затем выберите сервис по нужному формату, функциям и доступу. Один инструмент может подходить для нескольких задач; каталог помогает выбрать, но не заменяет проверку ответа.
