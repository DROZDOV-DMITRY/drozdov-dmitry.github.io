# Каталог ИИ-инструментов — единый источник данных

**Версия механизма:** V1.1.0 · 06.11.2026  
**Публикация:** https://drozdov-dmitry.github.io/school-ai-courses/  
**Статус:** GitHub Actions автоматизирует генерацию; Cloudflare Worker v0.2.1 не требует изменения кода при пополнении каталога.

## Где редактировать сервисы

**Только** `school-ai-courses/data/tools-registry.json`. Файлы ниже являются генерируемыми:

- `school-ai-courses/tools/index.html` — карточки ученического раздела внутри меток `COURSE_TOOLS_REGISTRY_START/END`;
- `school-ai-courses/adults/tools/index.html` — карточки взрослого раздела внутри меток;
- `school-ai-courses/tools/search-index.json` — индекс Groq для учеников;
- `school-ai-courses/adults/tools/search-index.json` — индекс Groq для взрослых.

Вне меток допускается редактирование оформления страниц. **Внутри меток** — только через реестр.

## Добавление сервиса

В массиве `services` создай один объект с уникальным `key` и названием `title`. В `views` добавь `school`, `adults` или оба. Это позволяет указывать сервис только в одном разделе.

Каждый `view` содержит:
- `id` — неизменяемый идентификатор карточки, например `tool-s44` для ученического или `tool-a44` для взрослого раздела;
- `order` — уникальный номер порядка внутри соответствующего раздела;
- `category`, `keywords` — параметры поиска (не менять по случайному совпадению слов);
- `html` — полный HTML одной карточки с теми же `id` и `data-ai-id`; её `<h3>` должно совпадать с `title`.

Сохраняй актуальные условия доступа, возрастные предупреждения, доступность функций, ссылки и нейтральные описания. **Возрастные категории сами по себе не исключают карточки из ИИ-поиска.** При добавлении нового сервиса не выдумывай информацию о нём.

При сохранении в `main` GitHub Actions `sync-course-tools.yml` выполняет генератор `scripts/sync-course-tools.mjs`, сверяет страницы с индексами и публикует четыре результата. Менять Cloudflare Worker при этом **не требуется**. Его кэш обновляется примерно каждые четыре минуты после следующего обращения к каталогу.

## Проверка

Локально в корне репозитория (Node.js 22+):

```bash
node scripts/sync-course-tools.mjs --write
node scripts/sync-course-tools.mjs --check
```

`--check` завершается ошибкой, если карточки или индексы не соответствуют реестру. Прямые изменения сгенерированных страниц/индексов без обновления реестра отклоняются контрольной задачей GitHub Actions, а не молча принимаются.

Текущая первоначальная база: **43 уникальных сервиса**, 43 в школьной и 43 во взрослой версии. Заявленные ранее 47+3 пока не обнаружены в проверенном публичном источнике: для их внедрения нужны первичные записи. Нельзя добавлять их по предположению.

## Защитные инварианты

- Существующие URL, стили карточек, возрастные примечания и локальный поиск сохранены.
- В каждом каталоге — от 10 до 120 записей, уникальные ID и порядковые номера; поддерживаемый Worker v0.2.1 требует двухзначные числовые ID (`tool-sNN` / `tool-aNN`).
- Рекомендации Groq валидируются по выбранному индексу; пользовательский текст не используется как команда.
- Секреты `GROQ_API_KEY`, `TURNSTILE_SECRET_KEY` не помещаются в публичный репозиторий.
- При недоступности Groq, Turnstile или Worker остаётся исходный локальный поиск.
