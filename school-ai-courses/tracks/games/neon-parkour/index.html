Неон-паркур: Побег из мегаполиса

Бег, прыжки, физика и неоновый город.

← К выбору игр

Игра для 7–8 класса. Ты — бегун на крышах неонового города. Перепрыгивай пропасти, уворачивайся от препятствий и собирай энергетические кристаллы, чтобы достичь портала на другой стороне уровня.

Для работы с файлом нужен компьютер с Windows 10/11. Блокнот и Microsoft Edge уже подходят.
Сейчас я с телефона — что делать?

На смартфоне выбери игру и прочитай задание. Создать файл и запустить его по этой инструкции сможешь позже на Windows-компьютере.

1

Подготовь папку и файл

Что должно получиться: на рабочем столе папка «Неон-паркур», внутри — файл neon-parkour.txt, открытый в Блокноте.

  1. Сначала включи показ расширений. Открой Проводник сочетанием Win + E. Windows 11: «Просмотреть → Показать → Расширения имён файлов». Windows 10: «Вид → Расширения имён файлов».
    Не знаю, как показать расширения
    1. Нажми клавишу Windows и E одновременно.
    2. В Проводнике найди «Вид» либо «Просмотреть».
    3. Включи «Расширения имён файлов» — теперь видно окончания .txt и .html.
  2. Создай папку «Неон-паркур». На рабочем столе нажми правой кнопкой на пустом месте → «Создать» → «Папку». Введи название и нажми Enter.
    Не знаю, как создать папку
    1. Нажми Win + D — откроется рабочий стол.
    2. Нажми правой кнопкой мыши на пустом месте.
    3. Выбери «Создать → Папку», назови её «Неон-паркур», нажми Enter.
  3. Создай neon-parkour.txt. Внутри папки нажми правой кнопкой → «Создать» → «Текстовый документ». Переименуй в neon-parkour.txt. Проверь, что не получилось neon-parkour.txt.txt.
    Не знаю, как создать файл
    1. Открой папку двойным щелчком.
    2. Правой кнопкой на пустом месте → «Создать → Текстовый документ».
    3. Напиши neon-parkour.txt, нажми Enter. Проверь окончание имени.
    Нет пункта «Текстовый документ»
    1. Через «Пуск» открой Блокнот.
    2. Выбери «Файл → Сохранить как» и папку «Неон-паркур» на рабочем столе.
    3. Выбери тип «Все файлы (*.*)», введи neon-parkour.txt и сохрани.
    4. В Проводнике проверь имя и расширение .txt.
  4. Открой файл в Блокноте. Дважды нажми neon-parkour.txt. Если открылась другая программа — правой кнопкой → «Открыть с помощью → Блокнот».
    Не открывается Блокнот

    Нажми правой кнопкой мыши на файле, выбери «Открыть с помощью» и найди «Блокнот»; при необходимости выбери «Другое приложение».

Проверь по настоящему экрану, прежде чем переходить к ИИ:

Галочки — только самопроверка. Сайт не видит содержимое компьютера. Если не получается, открой нужную подсказку или обратись к учителю.

2

Попроси ИИ создать игру

Твоё решение до работы ИИ: выбери одно изменение — героя, цвет, правило или сложность — и допиши его в запрос ниже. Достаточно одной фразы.

Это твой запрос. Прочитай его и при желании добавь свой замысел. Выбери цвет костюма героя, погоду или название мегаполиса.

Нажми «Скопировать», открой кнопку «ИИ-чат» вверху страницы или справа внизу, выбери ИИ-сервис, вставь запрос (Ctrl+V) и отправь его.

Точка возврата: после ответа ИИ вернись сюда к шагу 3 «Вставь код». Эту страницу не закрывай.

Не закрывай этот диалог с ИИ. Здесь сохраняется твой первый запрос и полученный код. Если игра потребует исправлений, ИИ сможет учитывать предыдущую версию и твои изменения.

3

Преврати текстовый файл в игру

  1. Подожди, пока ИИ закончит ответ. Скопируй весь HTML-код целиком, от <!doctype html> до </html>, без строк с тремя обратными кавычками.
  2. Вернись к Блокноту с файлом neon-parkour.txt. Вставь код через Ctrl+V, сохрани через Ctrl+S и закрой Блокнот.
  3. Показ расширений ты включил на шаге 1. Убедись, что отображается полное имя neon-parkour.txt. Если расширений не видно, вернись к шагу 1.
  4. Переименуй neon-parkour.txt в neon-parkour.html и подтверди изменение расширения. Проверь, что имя файла не заканчивается на .html.txt.
4

Запусти в Microsoft Edge и проверь

Найди neon-parkour.html в папке. Нажми на него правой кнопкой мыши → Открыть с помощью → Microsoft Edge. Если Edge не виден, выбери «Выбрать другое приложение».

Поиграй и проверь три вещи:

Если браузер показывает код вместо игры, проверь расширение файла. Если управление, физика или правила работают неправильно, запиши конкретную ошибку на следующем шаге.

5

Исправь ошибку или улучши игру

Запиши, что именно не получилось или что хочешь поменять. Вернись в диалог с ИИ, в котором создавал игру.

  1. Отправь запрос в тот же диалог с ИИ.
  2. Получив полный обновлённый код, нажми правой кнопкой на neon-parkour.html → Открыть с помощью → Блокнот.
  3. Нажми Ctrl+A, вставь новый код через Ctrl+V, сохрани через Ctrl+S.
  4. В Microsoft Edge обнови страницу через Ctrl+F5. Снова проверь игру.

Повторяй цикл. Перед крупной переделкой можешь сохранить работающую версию под именем neon-parkour-v1.html.

Сохрани и отправь свою игру

Итоговый файл — neon-parkour.html. Проверь ещё раз, что файл открывается в Microsoft Edge и игра работает.

  1. Открой MAX и выбери согласованный чат учителя, не общую школьную группу.
  2. Прикрепи именно файл neon-parkour.html, не скриншот и не только название. Не отправляй пароли и лишние персональные данные.
  3. Дождись завершения отправки и подтверждения учителя, что файл получен. Если MAX не принимает HTML, по согласованию с учителем упакуй его в ZIP и отправь архив.
  4. На школьном ПК удаляй временную папку только после подтверждения сохранения копии и согласно правилам учителя. Не удаляй единственный экземпляр.
Не знаю, как передать файл через MAX

Открой MAX → согласованный диалог учителя → кнопка прикрепления (обычно «+» или скрепка) → «Файл» → папка «Неон-паркур» на рабочем столе → neon-parkour.html → «Отправить». Если интерфейс другой, уточни по экрану у учителя.

Если MAX недоступен, сохрани оригинал и сообщи учителю. Сбой передачи не означает, что игра сделана неправильно.
