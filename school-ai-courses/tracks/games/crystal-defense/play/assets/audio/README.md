# Звуки (необязательный этап)

Этот каталог оставлен для дальнейшего расширения игры. Сейчас в пилоте звуковых файлов нет.

Для бесплатных эффектов см. https://kenney.nl/assets/rpg-audio (CC0).
Короткие OGG или MP3 должны иметь отдельную запись источника и лицензии в `../ASSETS_LICENSES.md`.

Не запускай музыку или звук автоматически до взаимодействия игрока. Обязательно добавь кнопку отключения звука, если реализуешь аудио.
