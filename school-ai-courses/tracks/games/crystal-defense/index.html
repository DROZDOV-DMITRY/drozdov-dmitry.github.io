1

Подготовь папку и файл

Что должно получиться: на рабочем столе папка «Кристальный рубеж», внутри — файл crystal-defense.txt, открытый в Блокноте.

  1. Сначала включи показ расширений.
    Не знаю, как показать расширения
    1. Открой Проводник сочетанием Win + E.
    2. В Windows 11 выбери «Просмотреть → Показать → Расширения имён файлов». В Windows 10 — «Вид → Расширения имён файлов».
    3. Убедись, что видны окончания файлов: .txt, .html.
  2. Создай папку «Кристальный рубеж».
    Не знаю, как создать папку
    1. Нажми Win + D — откроется рабочий стол.
    2. Нажми правой кнопкой мыши на пустом месте.
    3. Выбери «Создать → Папку», назови её «Кристальный рубеж», нажми Enter.
  3. Создай crystal-defense.txt.
    Не знаю, как создать файл
    1. Открой папку двойным щелчком.
    2. Нажми правой кнопкой на пустом месте → «Создать → Текстовый документ».
    3. Назови файл crystal-defense.txt и нажми Enter. Проверь полное имя: crystal-defense.txt, а не crystal-defense.txt.txt.
    Нет пункта «Текстовый документ»
    1. Через «Пуск» открой Блокнот.
    2. Выбери «Файл → Сохранить как» и папку «Кристальный рубеж» на рабочем столе.
    3. Выбери тип «Все файлы (*.*)», введи crystal-defense.txt и сохрани.
    4. В Проводнике проверь имя и расширение .txt.
  4. Открой файл в Блокноте.
    Не открывается Блокнот

    Дважды щёлкни по файлу crystal-defense.txt. Если открылась другая программа, нажми правой кнопкой на файле → «Открыть с помощью» → «Блокнот»; при необходимости выбери «Выбрать другое приложение».

Проверь на своём компьютере перед работой с ИИ:

Галочки — только самопроверка. Сайт не видит содержимое компьютера. Если не получается, открой нужную подсказку или обратись к учителю.

2

Придумай свою версию и попроси ИИ создать её

Сначала твоя идея: сыграй в образец и придумай собственное улучшение — новую башню, способность или особенность противников. Запиши его сам, до подсказок ИИ.

Это основа запроса, а не готовый ответ. Впиши своё изменение и художественный замысел. Не проси нейросеть копировать изображения чужой игры.

Нажми «Скопировать», открой кнопку «ИИ-чат» вверху страницы или справа внизу, выбери ИИ-сервис, вставь запрос через Ctrl+V и отправь его.

Точка возврата: после ответа ИИ вернись сюда к шагу 3 «Вставь код». Эту страницу не закрывай.

Не закрывай этот диалог с ИИ. Он сохраняет твой запрос и полученный код. При исправлении ИИ сможет учитывать предыдущую версию и внесённые изменения.

3

Преврати текстовый файл в игру

  1. Подожди, пока ИИ закончит ответ. Скопируй весь HTML-код целиком, от <!doctype html> до </html>, без строк с тремя обратными кавычками.
  2. Вернись к Блокноту с файлом crystal-defense.txt. Вставь код через Ctrl+V, сохрани через Ctrl+S и закрой Блокнот.
  3. Показ расширений ты включил на шаге 1. Убедись, что отображается полное имя crystal-defense.txt. Если расширений не видно, вернись к шагу 1.
  4. Переименуй crystal-defense.txt в crystal-defense.html и подтверди изменение расширения. Проверь, что имя файла не заканчивается на .html.txt.
4

Запусти и проверь на разных экранах

Найди crystal-defense.html в папке. Нажми на него правой кнопкой мыши → Открыть с помощью → Microsoft Edge. Если Edge не виден, выбери «Выбрать другое приложение».

Проверь собственную игру на компьютере. Затем открой образец на смартфоне и сравни удобство. Для своей версии также проверь касания, если доступна передача HTML на телефон:

Если браузер показывает код вместо игры, проверь расширение файла. Если управление, правила или графика работают неправильно, запиши конкретную ошибку.

5

Исправь ошибку или улучши игру

Опиши обнаруженную ошибку или желаемое улучшение. Вернись в диалог с ИИ, в котором создавал игру.

  1. Отправь скопированный запрос в тот же диалог с ИИ.
  2. Получив полный обновлённый код, нажми правой кнопкой на crystal-defense.html → Открыть с помощью → Блокнот.
  3. Нажми Ctrl+A, вставь новый код через Ctrl+V, сохрани через Ctrl+S.
  4. В Microsoft Edge обнови страницу через Ctrl+F5. Снова проверь игру.

Перед большим изменением можешь сохранить предыдущую версию под именем crystal-defense-v1.html.

Сохрани и отправь свою игру

Итоговый файл — crystal-defense.html. Проверь ещё раз, что файл открывается в Microsoft Edge и игра работает.

  1. Открой MAX и выбери согласованный чат учителя, не общую школьную группу.
  2. Прикрепи именно файл crystal-defense.html, не скриншот и не только название. Не отправляй пароли и лишние персональные данные.
  3. Дождись завершения отправки и подтверждения учителя, что файл получен. Если MAX не принимает HTML, по согласованию с учителем упакуй его в ZIP и отправь архив.
  4. На школьном ПК удаляй временную папку только после подтверждения сохранения копии и согласно правилам учителя. Не удаляй единственный экземпляр.
Не знаю, как передать файл через MAX

Открой MAX → согласованный диалог учителя → кнопка прикрепления (обычно «+» или скрепка) → «Файл» → папка «Кристальный рубеж» на рабочем столе → crystal-defense.html → «Отправить». Если интерфейс другой, уточни по экрану у учителя.

Если MAX недоступен, сохрани оригинал и сообщи учителю. Сбой передачи не означает, что игра сделана неправильно.
