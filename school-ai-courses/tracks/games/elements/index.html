1

Сначала приготовь папку и пустой файл

  1. На рабочем столе Windows нажми правой кнопкой мыши → Создать → Папку. Назови её как хочешь, например Битва стихий.
  2. Открой папку. Нажми правой кнопкой → Создать → Текстовый документ.
  3. Назови текстовый файл stihii.txt. Открой его двойным щелчком в Блокноте.
  4. Оставь пустой Блокнот открытым. Пока это обычный .txt-файл. Только теперь переходи к ИИ.

Если пункт «Текстовый документ» отсутствует, сообщи преподавателю.

2

Попроси ИИ создать игру

Это твой запрос. Прочитай его и по желанию добавь своё изменение. Можешь заменить стихийных персонажей на собственных героев и изменить оформление арены.

Нажми «Скопировать», открой кнопку «ИИ-чат» вверху страницы или справа внизу, выбери разрешённый преподавателем сервис и вставь запрос (Ctrl+V). Отправь его.

Не создавай личный аккаунт без разрешения преподавателя. Для исправлений возвращайся в тот же разговор с ИИ.

3

Преврати текстовый файл в игру

  1. Подожди, пока ИИ закончит ответ. Скопируй весь HTML-код целиком, от <!doctype html> до </html>, без строк с тремя обратными кавычками.
  2. Вернись к открытому Блокноту с файлом stihii.txt. Вставь код сочетанием Ctrl+V, сохрани через Ctrl+S и закрой Блокнот.
  3. В папке включи показ расширений: Windows 11: Просмотреть → Показать → Расширения имён файлов; Windows 10: Вид → Расширения имён файлов.
  4. Переименуй stihii.txt в stihii.html и подтверди изменение расширения. Проверь, что имя не заканчивается на .html.txt.

Важно: код должен оставаться в твоём собственном файле. Сайт за тебя его не создаёт.

4

Запусти в Microsoft Edge и проверь

Найди stihii.html в папке. Нажми на него правой кнопкой мыши → Открыть с помощью → Microsoft Edge. Если Edge не виден, выбери «Выбрать другое приложение».

Поиграй и проверь три вещи:

Если браузер показывает текст кода вместо игры, проверь расширение файла. Если игра ведёт себя странно, опиши конкретную ошибку на следующем шаге.

5

Исправь ошибку или улучши игру

Не закрывай прежний диалог с ИИ. Запиши, что именно не получилось или что хочешь поменять. Не нужно начинать новый чат.

  1. Отправь скопированный запрос в тот же диалог с ИИ.
  2. Получив новый полный код, нажми правой кнопкой на stihii.html → Открыть с помощью → Блокнот.
  3. Нажми Ctrl+A, вставь новый код Ctrl+V, сохрани Ctrl+S.
  4. В Microsoft Edge обнови страницу через Ctrl+F5. Снова проверь игру.

Повторяй цикл столько раз, сколько нужно. Если прежняя версия работала, перед крупным изменением сохрани её копию, например stihii-v1.html.

Готово! Ты создал игру, запустил её из собственного файла и проверил результат. Объясни преподавателю одну ошибку или улучшение, которое удалось сделать.
