Битва стихий

Три силы, случайный противник и правила, которые должны работать без ошибок.

← К выбору игр

Игра для 4–6 класса. Игрок выбирает Огонь, Воду или Листья. Компьютер отвечает случайным выбором. Побеждает тот, кто первым выиграет пять раундов.

Для работы с файлом нужен компьютер с Windows 10/11. Блокнот и Microsoft Edge уже подходят.
Сейчас я с телефона — что делать?

На смартфоне выбери игру и прочитай задание. Создать файл и запустить его по этой инструкции сможешь позже на Windows-компьютере.

1

Подготовь папку и файл

Что должно получиться: на рабочем столе папка «Битва стихий», внутри — файл stihii.txt, открытый в Блокноте.

  1. Сначала включи показ расширений.
    Не знаю, как показать расширения
    1. Открой Проводник сочетанием Win + E.
    2. В Windows 11 выбери «Просмотреть → Показать → Расширения имён файлов». В Windows 10 — «Вид → Расширения имён файлов».
    3. Убедись, что видны окончания файлов: .txt, .html.
  2. Создай папку «Битва стихий».
    Не знаю, как создать папку
    1. Нажми Win + D — откроется рабочий стол.
    2. Нажми правой кнопкой мыши на пустом месте.
    3. Выбери «Создать → Папку», назови её «Битва стихий», нажми Enter.
  3. Создай stihii.txt.
    Не знаю, как создать файл
    1. Открой папку двойным щелчком.
    2. Нажми правой кнопкой на пустом месте → «Создать → Текстовый документ».
    3. Назови файл stihii.txt и нажми Enter. Проверь полное имя: stihii.txt, а не stihii.txt.txt.
    Нет пункта «Текстовый документ»
    1. Через «Пуск» открой Блокнот.
    2. Выбери «Файл → Сохранить как» и папку «Битва стихий» на рабочем столе.
    3. Выбери тип «Все файлы (*.*)», введи stihii.txt и сохрани.
    4. В Проводнике проверь имя и расширение .txt.
  4. Открой файл в Блокноте.
    Не открывается Блокнот

    Дважды щёлкни по файлу stihii.txt. Если открылась другая программа, нажми правой кнопкой на файле → «Открыть с помощью» → «Блокнот»; при необходимости выбери «Выбрать другое приложение».

Проверь по настоящему экрану, прежде чем переходить к ИИ:

Галочки — только самопроверка. Сайт не видит содержимое компьютера. Если не получается, открой нужную подсказку или обратись к учителю.

2

Попроси ИИ создать игру

Твоё решение до работы ИИ: выбери одно изменение — героя, цвет, правило или сложность — и допиши его в запрос ниже. Достаточно одной фразы.

Это твой запрос. Прочитай его и по желанию добавь своё изменение. Можешь заменить стихийных персонажей на собственных героев и изменить оформление арены.

Нажми «Скопировать», открой кнопку «ИИ-чат» вверху страницы или справа внизу, выбери ИИ-сервис и вставь запрос (Ctrl+V). Отправь его.

Точка возврата: после ответа ИИ вернись сюда к шагу 3 «Вставь код». Эту страницу не закрывай.

Не закрывай этот диалог с ИИ. Здесь сохраняется твой первый запрос и полученный код. Когда захочешь исправить ошибку или добавить что-то новое, ИИ сможет учитывать предыдущую версию игры.

3

Преврати текстовый файл в игру

  1. Подожди, пока ИИ закончит ответ. Скопируй весь HTML-код целиком, от <!doctype html> до </html>, без строк с тремя обратными кавычками.
  2. Вернись к открытому Блокноту с файлом stihii.txt. Вставь код сочетанием Ctrl+V, сохрани через Ctrl+S и закрой Блокнот.
  3. Показ расширений ты включил на шаге 1. Убедись, что отображается полное имя stihii.txt. Если расширений не видно, вернись к шагу 1.
  4. Переименуй stihii.txt в stihii.html и подтверди изменение расширения. Проверь, что имя не заканчивается на .html.txt.
4

Запусти в Microsoft Edge и проверь

Найди stihii.html в папке. Нажми на него правой кнопкой мыши → Открыть с помощью → Microsoft Edge. Если Edge не виден, выбери «Выбрать другое приложение».

Поиграй и проверь три вещи:

Если браузер показывает текст кода вместо игры, проверь расширение файла. Если игра ведёт себя странно, опиши конкретную ошибку на следующем шаге.

5

Исправь ошибку или улучши игру

Запиши, что именно не получилось или что хочешь поменять. Вернись в диалог с ИИ, в котором создавал игру.

  1. Отправь скопированный запрос в тот же диалог с ИИ.
  2. Получив новый полный код, нажми правой кнопкой на stihii.html → Открыть с помощью → Блокнот.
  3. Нажми Ctrl+A, вставь новый код Ctrl+V, сохрани Ctrl+S.
  4. В Microsoft Edge обнови страницу через Ctrl+F5. Снова проверь игру.

Повторяй цикл столько раз, сколько нужно. Если прежняя версия работала, перед крупным изменением сохрани её копию, например stihii-v1.html.

Сохрани и отправь свою игру

Итоговый файл — stihii.html. Проверь ещё раз, что файл открывается в Microsoft Edge и игра работает.

  1. Открой MAX и выбери согласованный чат учителя, не общую школьную группу.
  2. Прикрепи именно файл stihii.html, не скриншот и не только название. Не отправляй пароли и лишние персональные данные.
  3. Дождись завершения отправки и подтверждения учителя, что файл получен. Если MAX не принимает HTML, по согласованию с учителем упакуй его в ZIP и отправь архив.
  4. На школьном ПК удаляй временную папку только после подтверждения сохранения копии и согласно правилам учителя. Не удаляй единственный экземпляр.
Не знаю, как передать файл через MAX

Открой MAX → согласованный диалог учителя → кнопка прикрепления (обычно «+» или скрепка) → «Файл» → папка «Битва стихий» на рабочем столе → stihii.html → «Отправить». Если интерфейс другой, уточни по экрану у учителя.

Если MAX недоступен, сохрани оригинал и сообщи учителю. Сбой передачи не означает, что игра сделана неправильно.
