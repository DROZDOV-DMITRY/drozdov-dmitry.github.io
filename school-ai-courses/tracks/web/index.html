Мастерская первого сайта

Пройди шаги по очереди. Тема и оформление будут твоими — ИИ поможет их найти и воплотить.

1

Выясни вместе с ИИ, какой сайт хочешь

Начни с разговора: расскажи ИИ, что тебе нравится. Пусть задаёт вопросы и помогает выбрать идею. Код пока не нужен.

Нажми «ИИ-чат» в верхнем меню или справа внизу, выбери чат, вставь запрос через Ctrl+V. Сохрани этот диалог: в нём будут все решения для дальнейших шагов.

2

Придумай устройство сайта

После выбора темы реши, какие разделы нужны, что в них разместить и какую кнопку увидит посетитель.

Отправь его в тот же диалог с ИИ. Согласуй схему страницы, прежде чем переходить к оформлению.

3

Выбери стиль — быстрый или подробный

Можно определиться за пару минут или разработать собственную палитру, типографику и композицию.

Три идеи оформления, затем твой выбор цветов и настроения.

Два художественных направления, затем точные цвета, шрифты, сетка, карточки и детали.

Выбранный стиль тоже согласуй в том же диалоге.

4

Приготовь файл на рабочем столе

Где ты: шаг 4 из 7. Цель: папка своего сайта с единственным пустым файлом index.txt, открытым в Блокноте. Нужен Windows-компьютер; со смартфона пока можно продумать тему и стиль.

  1. Сначала включи расширения файлов.
    Не знаю, где найти расширения

    Открой Проводник клавишами Win + E. В Windows 11 выбери «Просмотреть» → «Показать» → «Расширения имён файлов»; в Windows 10 — «Вид» → «Расширения имён файлов». Убедись, что стали видны окончания имён файлов, например .txt и .html.

  2. Создай папку на рабочем столе.
    Не знаю, как создать папку

    Нажми Win + D, чтобы перейти на рабочий стол. Нажми правой кнопкой мыши на пустом месте → «Создать» → «Папку». Дай папке название своего сайта и нажми Enter. Открой её двойным нажатием.

  3. Создай в папке файл index.txt.
    Не знаю, как создать текстовый файл

    Открой созданную папку. Нажми правой кнопкой на пустом месте внутри → «Создать» → «Текстовый документ». Назови файл index.txt и нажми Enter. Проверь, что полное имя — index.txt, а не index.txt.txt.

    Нет пункта «Текстовый документ»

    Запусти Блокнот через меню «Пуск» → «Файл» → «Сохранить как». Выбери свою папку, тип «Все файлы (*.*)» и имя index.txt. Проверь полное имя в Проводнике.

  4. Открой index.txt в Блокноте и оставь файл пустым.
    Не открывается Блокнот

    Нажми правой кнопкой на файле → «Открыть с помощью» → «Блокнот». Если его нет, выбери «Выбрать другое приложение».

Самопроверка перед обращением к ИИ

Всё готово → к шагу 5 «Получи код»

Эти отметки — твоя самопроверка, сайт не имеет доступа к файлам Windows. Если что-то не получилось, открой нужную подсказку выше.
5

Получи код своего сайта

Когда идея, структура и стиль согласованы, отправь ИИ последний запрос на разработку HTML.

  1. Скопируй ответ ИИ — весь HTML-код, от <!doctype html> до </html>, без строк из трёх обратных кавычек.
  2. Вставь его в открытый Блокнот (Ctrl+V) и сохрани (Ctrl+S).
  3. Переименуй index.txt в index.html.
    Вместо сайта появился текст или не получается переименовать

    В Проводнике нажми правой кнопкой на файле → «Переименовать», введи index.html и подтверди изменение расширения, если Windows спросит. Проверь, что отображение расширений включено: полное имя должно быть index.html, а не index.html.txt. Если есть лишнее .txt, убери его через «Переименовать».

  4. Открой index.html в Microsoft Edge.
    Не вижу Edge или открылся Блокнот

    Нажми правой кнопкой на index.html, выбери «Открыть с помощью» → «Выбрать другое приложение» → Microsoft Edge. Если браузер показывает исходный код, проверь расширение файла.

Если сайт уже выглядит так, как ты задумал: Публикация с ИИ-проводником →

6

Проверь и улучши

Проверь результат на компьютере. Если есть ошибка или появилась новая идея, попроси ИИ изменить код и сохрани новую версию.

Точка возврата: после ответа ИИ вернись на эту страницу к шагу 5, а после исправления — к шагу 6. Не создавай новый проект из-за ошибки.

Отправь запрос в прежний диалог → получи полный новый HTML → открой index.html в Блокноте → Ctrl+A, Ctrl+V, Ctrl+S → обнови страницу браузера (Ctrl+F5).

7

Зарегистрируй и опубликуй сайт на GitHub

Когда сайт готов, переходи к публикации. ИИ проведёт тебя от регистрации на GitHub до собственной ссылки на GitHub Pages — по одному действию.

Публикация — открыть GitHub-Навигатор →

ИИ проведёт по экрану GitHub на английском, поможет с почтой, репозиторием и настройкой Pages.
