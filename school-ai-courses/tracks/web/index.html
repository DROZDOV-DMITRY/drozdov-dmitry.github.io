Мастерская первого сайта

Пройди шаги по очереди. Тема и оформление будут твоими — ИИ поможет их найти и воплотить.

1

Выясни вместе с ИИ, какой сайт хочешь

Начни с разговора: расскажи ИИ, что тебе нравится. Пусть задаёт вопросы и помогает выбрать идею. Код пока не нужен.

Нажми «ИИ-чат» в верхнем меню или справа внизу, выбери чат, вставь запрос через Ctrl+V. Сохрани этот диалог: в нём будут все решения для дальнейших шагов.

2

Придумай устройство сайта

После выбора темы реши, какие разделы нужны, что в них разместить и какую кнопку увидит посетитель.

Отправь его в тот же диалог с ИИ. Согласуй схему страницы, прежде чем переходить к оформлению.

3

Выбери стиль — быстрый или подробный

Можно определиться за пару минут или разработать собственную палитру, типографику и композицию.

Три идеи оформления, затем твой выбор цветов и настроения.

Два художественных направления, затем точные цвета, шрифты, сетка, карточки и детали.

Выбранный стиль тоже согласуй в том же диалоге.

4

Приготовь файл на рабочем столе

  1. Нажми на рабочем столе Windows правой кнопкой мыши → Создать → Папку. Дай папке название своего сайта.
  2. Внутри папки нажми правой кнопкой → Создать → Текстовый документ.
  3. Назови документ index.txt, открой его в Блокноте и оставь пустым. Теперь можно получать HTML-код.
5

Получай код своего сайта

Когда идея, структура и стиль согласованы, отправь ИИ последний запрос на разработку HTML.

  1. Скопируй ответ ИИ — весь HTML-код, от <!doctype html> до </html>, без строк из трёх обратных кавычек.
  2. Вставь его в открытый Блокнот (Ctrl+V) и сохрани (Ctrl+S).
  3. В Проводнике включи отображение расширений файлов. Переименуй index.txt в index.html, подтверди изменение расширения.
  4. Нажми на index.html правой кнопкой → Открыть с помощью → Microsoft Edge.
6

Проверь и улучши

Проверь результат на компьютере. Если есть ошибка или появилась новая идея, попроси ИИ изменить код и сохрани новую версию.

Отправь запрос в прежний диалог → получи полный новый HTML → открой index.html в Блокноте → Ctrl+A, Ctrl+V, Ctrl+S → обнови страницу браузера (Ctrl+F5).

7

Зарегистрируй и опубликуй сайт на GitHub

Когда сайт готов, переходи к публикации. ИИ проведёт тебя от регистрации на GitHub до собственной ссылки на GitHub Pages — по одному действию.

Перейти к регистрации и публикации →

GitHub допускает самостоятельные аккаунты с 13 лет. Для младших школьников публикацию выполняет взрослый со своего аккаунта.
