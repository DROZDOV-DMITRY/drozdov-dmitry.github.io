Как спросить Наставника так, чтобы он помог

Хороший запрос — это не длинный текст. Нужно быстро назвать устройство, программу, наблюдаемый симптом и попросить одно конкретное следующее действие.

Важно: встроенный Наставник сайта ещё не реализован. Сейчас этот же навык тренируем через любой ИИ из меню «ИИ-чат»; архитектура урока не зависит от конкретного провайдера.

Мне это легко · экспресс-проверка ≈ 3 минуты

Сформулируй запрос без шаблона

Ситуация: у тебя Windows, в Microsoft Edge сайт видит камеру, но не слышит микрофон. Ты уже обновил страницу — ничего не изменилось.

Не уверен → обычный урок
Проверка ещё не выполнена.
○названо устройство / система
○названа программа
○описан наблюдаемый симптом
○есть просьба дать одно следующее действие
Все четыре элемента есть → FAST CHALLENGE

1. Плохой запрос и рабочий запрос

Не помогает

«У меня не работает. Что делать?»

ИИ не знает устройство, программу и симптом.

Помогает

«У меня Windows, Microsoft Edge. Сайт не видит микрофон, после обновления страницы ничего не изменилось. Дай одно безопасное следующее действие.»

Сделай: в Блокноте перепиши плохой запрос так, чтобы в нём появились все четыре элемента: устройство, программа, симптом, один следующий шаг.
0:00–7:00

2. Собери запрос из фактов

Не начинай с догадки «сломался драйвер». Сначала опиши то, что реально видишь.

Нажми «Собрать запрос».
7:00–15:00

3. Спроси один из доступных ИИ

Открой меню «ИИ-чат» в шапке или справа внизу и выбери сервис. Вставь собранный запрос.

Сайт не выбирает модель за тебя. Задача урока — научиться давать достаточный контекст любому подходящему ИИ.

Важно: не выполняй длинную цепочку автоматически. Возьми только первое безопасное действие, выполни его и вернись на эту страницу.
15:00–23:00

4. Сообщи результат действия

1. Спросил
2. Получил один шаг
3. Выполнил
4. Сообщил результат

ИИ не видит, что случилось после его совета. Эту информацию должен вернуть ты.

Проверка ещё не выполнена.
23:00–30:00

5. Финальная задача — без формы и шаблона

Новая ситуация: в Windows ты хочешь найти настройку «Ночной свет», но не знаешь, где она находится. Не проси преподавателя.

Самостоятельно:

1. сформулируй запрос к выбранному ИИ;
2. попроси одно действие;
3. выполни его;
4. сообщи ИИ, что увидел;
5. найди нужную настройку, но не обязан менять её значение.

Доказательство освоения: ты дошёл до нужной настройки без пошаговой инструкции преподавателя и можешь показать историю «вопрос → действие → результат».

30:00–40:00

FAST CHALLENGE · реши новую проблему через цикл

Ситуация: в Windows звук есть, но он идёт не в те наушники/колонки. Сам выбери ИИ через меню сайта и реши задачу по правилу:

контекст → один вопрос → одно действие → проверка → сообщение результата.

Не используй преподавателя как первый источник инструкции.
