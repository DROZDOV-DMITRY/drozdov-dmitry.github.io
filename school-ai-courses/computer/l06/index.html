Копия, перенос и имя файла

Сегодня важно не просто «перетащить что-то куда-то», а понимать результат: при копировании исходник остаётся, при переносе — меняет место, а переименование не должно случайно менять расширение.

Мне это легко · FAST_GATE ≈ 4 минуты

Докажи разницу без подсказок

Если у тебя уже есть два безопасных учебных файла, используй их. Если подходящих файлов нет — переходи к обычному уроку.

Файл A: скопируй в другую папку и переименуй копию. Исходный A должен остаться на старом месте.
Файл B: перемести в третью папку и переименуй. На старом месте B остаться не должен.
Если расширение видно — не меняй его.

1. Разминка + подготовь два безопасных файла

4–6 минут печати: открой Блокнот и без копирования набери две короткие строки о сегодняшнем уроке. Следи за точностью, а не за рекордом скорости.

Подготовка среды, не новый оцениваемый навык: если в папке Курс ИИ — L05 → Входящие нет двух безопасных учебных файлов, создай в Блокноте два простых текстовых файла: Файл-A.txt и Файл-B.txt. Если Windows скрывает расширение, не пытайся добавлять или удалять его вручную.
0:00–7:00

2. Копия: исходник остаётся

КОПИРОВАТЬ

Получается второй экземпляр. Исходный файл остаётся там, где был.

ПЕРЕМЕСТИТЬ

Файл меняет место. В старой папке его больше нет.

ВходящиеФайл-A.txt
→
ПрактикаФайл-A.txt

Скопируй Файл-A из «Входящие» в «Практика». Можно использовать уже знакомые Ctrl+C → Ctrl+V или команды Проводника.

Проверь: после копирования Файл-A должен быть виден в двух местах.
7:00–15:00

3. Перенос: исходное место освобождается

ВходящиеФайл-B.txt
→
ГотовоФайл-B.txt

Перемести Файл-B из «Входящие» в «Готово». Один способ — команда Вырезать, затем Вставить. Точное расположение команды в интерфейсе может отличаться; оценивается результат, а не конкретная кнопка.

Сначала выполни перенос, затем выбери результат.
15:00–23:00

4. Переименуй оба результата и не трогай расширение

Имя и расширение — не одно и то же.
Если видишь Файл-A.txt, то Файл-A — имя, а .txt — расширение. Переименуй только смысловую часть имени. Если расширение скрыто, просто не пытайся дописывать новое.

В «Практика» переименуй копию A в Копия-L06. В «Готово» переименуй перенесённый B в Перенесено-L06. Используй любой знакомый способ переименования.

Выбери безопасный результат переименования.
У меня Windows, Проводник. Я переименовываю учебный файл и не хочу случайно изменить его расширение. Дай одно безопасное действие, чтобы проверить имя перед подтверждением.
23:00–30:00

5. Финальная задача — по требованию, без пошаговой инструкции

Используй два новых безопасных файла или повтори упражнение с новыми именами.

Требование: один файл должен остаться в исходной папке и получить копию в «Практика». Второй файл должен исчезнуть из исходной папки и оказаться в «Готово». В новых местах переименуй оба, сохранив расширение.

После выполнения ответь себе: почему у первого осталось два экземпляра, а у второго — один?

FAST CHALLENGE · объясни результат до действия

Возьми два безопасных файла и три папки. До каждого действия вслух предскажи, где файл будет находиться после операции. Затем:

1. один файл скопируй и переименуй копию;
2. второй перемести и переименуй;
3. проверь свой прогноз по фактическому содержимому папок;
4. объясни одной фразой различие «копировать» и «переместить».
