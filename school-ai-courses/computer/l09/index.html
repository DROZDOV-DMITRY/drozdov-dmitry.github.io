Скачал — теперь найди

Скачать файл — только половина задачи. Нужно найти его в браузере, затем как настоящий файл в Проводнике и определить его тип.

Мне это легко · экспресс-проверка ≈ 4 минуты

Скачай файл и найди, куда он попал

Сначала на Рабочем столе создай папку «Быстрая загрузка».

Теперь нажми один раз: страница создаст безопасный учебный файл без личных данных.

Без ИИ: найди файл в списке загрузок браузера, затем найди его в Проводнике. После этого перемести файл в папку «Быстрая загрузка» на Рабочем столе и уже там открой его свойства.

Сайт проверяет только наличие вставленных изображений; имя, место и тип проверяются глазами.

1. Создай папку и скачай учебный файл

На Рабочем столе создай папку «Тренировка загрузок». Если после экспресс-проверки осталась папка «Быстрая загрузка», сначала удали её.

Теперь скачай первый учебный файл:

Браузер может сохранить файл автоматически или спросить место. Не запоминай «магическую папку»: определяй фактическое место сохранения. Если браузер блокирует или помечает файл как опасный, не отключай защиту и не обходи предупреждение — остановись и сообщи преподавателю.

0:00–8:00

2. Маршрут №1: найди загрузку в браузере

Открой список загрузок своего браузера и найди Старт-загрузка.txt. На Windows в актуальных Yandex Browser и Microsoft Edge это можно сделать сочетанием Ctrl+J. В другом браузере используй пункт Загрузки / Downloads в меню. Точная кнопка может отличаться — оценивается результат.

Проверь: имя совпадает с Старт-загрузка.txt. Если браузер показывает путь или команду открытия расположения файла, запомни это для следующего шага.
8:00–14:00

3. Маршрут №2: найди тот же файл в Проводнике

Открой Проводник и найди Старт-загрузка.txt там, куда его действительно сохранил браузер. После этого перемести файл в «Рабочий стол → Тренировка загрузок».

Проверка: файл должен лежать в папке «Тренировка загрузок», которую ты создал сам. Если список в исходном месте большой, используй поиск по имени.
14:00–22:00
У меня Windows. В браузере я вижу загрузку «Старт-загрузка.txt», но не могу найти этот файл в Проводнике. Дай одно безопасное действие, чтобы определить его фактическое место хранения.

4. Определи тип файла, не угадывая по иконке

Открой папку «Тренировка загрузок», выдели Старт-загрузка.txt → правый клик → Свойства → найди строку «Тип файла».

Здесь важно не угадать по значку, а посмотреть, что о файле сообщает Windows.

Для Урок 9 достаточно назвать тип так, как его показывает Windows.

Видимое расширение может быть подсказкой, но здесь не является условием прохождения.

22:00–30:00
