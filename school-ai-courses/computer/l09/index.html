✦ Миссия: найти пропажу

Куда пропал файл?

Ты только что скачал файл. Теперь найди его, перенеси в свою папку и узнай, что Windows о нём знает.

🎯
Что получится в конце

Файл окажется в нужной папке, а ты найдёшь его тип в свойствах Windows.

1Приготовь место

Представь: загрузил файл для задания, а он затерялся среди других. Чтобы такого не было, сначала приготовим для него отдельную папку.

На Рабочем столе щёлкни правой кнопкой по пустому месту → выбери «Создать» → «Папку» → напиши Тренировка загрузок и нажми Enter. Если такая папка уже есть, используй её.
📁

2Найди первый файл

1

Скачай учебный файл

Нажми на кнопку. Файл Старт-загрузка.txt — обычный учебный текст. В нём нет твоих личных данных.

⬇Скачать Старт-загрузка.txt

Когда браузер закончит загрузку, не ищи файл наугад. Сейчас откроем список загрузок.

2

Открой список загрузок

Посмотри в правый верхний угол браузера: там может появиться значок загрузок ⬇. Нажми на него. Если значка нет, нажми на клавиатуре Ctrl+J — в Microsoft Edge и Яндекс Браузере так открывается список загрузок.

Пример: сочетание клавиш открывает список. Вид браузера на твоём компьютере может немного отличаться.

Не сработало сочетание клавиш?

Открой меню браузера и выбери «Загрузки». В некоторых версиях браузера значок загрузок появляется рядом с адресной строкой. Нажми на него.

В другом браузере сочетание может отличаться — тогда ищи пункт «Загрузки» в меню.

3

Попроси браузер показать файл

Найди в списке Старт-загрузка.txt и нажми «Показать в папке». Браузер откроет Проводник и подсветит нужный файл.

Это схема, а не снимок твоего экрана: названия могут выглядеть чуть иначе.

Не вижу «Показать в папке»

Открой Проводник Windows: нажми значок жёлтой папки на панели задач. Слева выбери «Загрузки» и найди Старт-загрузка.txt. Если список длинный, щёлкни по нему и начни печатать имя файла.

4

Перенеси файл в свою папку

Когда файл выделен в Проводнике, нажми Ctrl+X — это вырезать. Открой на Рабочем столе папку «Тренировка загрузок» и нажми Ctrl+V — это вставить. Файл переместится туда.

Выдели файлCtrl+X→Открой папкуCtrl+V

Если удобнее мышью: щёлкни по файлу правой кнопкой, выбери «Вырезать». Открой папку, щёлкни по пустому месту правой кнопкой и нажми «Вставить».

5

Узнай тип файла

В открытой папке щёлкни по файлу правой кнопкой и выбери «Свойства». Найди строку «Тип файла». Windows сообщит тип — у нашего файла это текстовый документ.

Значок может меняться, а строка «Тип файла» показывает сведения Windows.

Не вижу строку «Тип файла»

Проверь, что открыл именно «Свойства», а не просто переименовал файл. На вкладке «Общие» строка обычно находится в верхней части окна. Ничего в свойствах менять не нужно — только прочитай тип и закрой окно.

3Теперь попробуй сам

Новая находка!

Потренируйся ещё раз — теперь с другим файлом. Подсказки остаются рядом, но порядок действий выбери сам.

  1. Скачай файл Тренировка-следопыт.txt.
  2. Найди его в браузере, а затем в Проводнике.
  3. Перенеси его в папку «Тренировка загрузок».
  4. Открой свойства и прочитай тип.

Получилось? Значит, теперь ты умеешь находить скачанный файл и приводить его в порядок. Если застрял, вернись к картинке нужного шага выше.

🏁

Миссия выполнена

Оба файла лежат в папке «Тренировка загрузок», а тип ты узнал по сведениям Windows. Теперь потерянную загрузку ты сможешь найти сам.
