Посчитал → записал → нашёл → удалил

Первый урок — не про «где какая кнопка». Ты сразу пройдёшь настоящий рабочий цикл Windows: проверишь себя Калькулятором, создашь свою папку, сохранишь файл, найдёшь его поиском, разберёшься с Корзиной и отправишь итог себе через MAX.

Уже всё это умею · FAST ≈ 7 минут

Пройди цепочку без подсказок

Создай на Рабочем столе папку со своим именем. В Блокноте сохрани в неё файл Проба с любой абракадаброй. Закрой Блокнот. Найди свою папку не глазами, а поиском в Проводнике. Удали «Проба», найди его в Корзине и удали окончательно. Затем создай в папке новый файл Финиш, отправь его себе через MAX, убедись, что он появился в MAX, и только после этого удали папку обычным способом.

Справился → FAST CHALLENGEЕсть пробел → обычный маршрут

FAST проверяет действие, а не знание терминов. Никакого штрафа за переход в обычный маршрут.

1. Сначала голова, потом Калькулятор

Попробуй посчитать в уме:
47 × 99
Не открывай Калькулятор сразу.
1
99 — это почти 100.
Сначала считаем 47 × 100 = 4700.
2
Теперь надо вычесть 47. Но вычесть 50 проще:
4700 − 50 = 4650.
3
Мы вычли 50, хотя нужно было вычесть 47. Значит, вычли на 3 больше. Возвращаем эти 3:
4650 + 3 = 4653.
4
Ответ: 4653. Теперь проверим себя Калькулятором.
Твоя попытка: посчитай в уме 68 × 99 тем же способом. Затем открой Калькулятор через поиск Windows и проверь результат.

2. Создай свою рабочую папку

На Рабочем столе создай новую папку и назови её своим именем. Если в классе два одинаковых имени — добавьте первую букву фамилии.

Способ: правый клик по свободному месту Рабочего стола → создать папку → ввести имя → Enter.
Дмитрий
7:00–12:00

3. Напиши абракадабру и просто сохрани

Через поиск Windows открой Блокнот. Напиши:

Абракадабра. Синий ёжик едет на лифте на Луну.

Сохрани документ.

Можно мышкой: Файл → СохранитьилиCtrl+S

При первом сохранении выбери на Рабочем столе папку со своим именем. В поле имени файла напиши Проба и нажми «Сохранить».

Сохранение нового файла

4. Найди свою папку не глазами

Закрой Блокнот. Теперь найди папку через поиск в Проводнике.

Открой Проводник:Win+E
Дальше: выбери Рабочий стол → в поле поиска напечатай имя своей папки → открой найденную папку → проверь, что внутри есть Проба.

5. Удали «Проба» и найди его в Корзине

В своей папке выбери файл Проба и удали его обычным способом.

Открой Корзину на Рабочем столе и найди там Проба.

Проверка: «Проба» исчез из твоей папки и появился в Корзине.
25:00–29:00

6. Удали «Проба» из Корзины окончательно

В Корзине выбери Проба → нажми команду Удалить → подтверди окончательное удаление.

Проверь: после подтверждения файла Проба больше нет в Корзине.
29:00–32:00

7. Финал: создай файл и отправь его себе через MAX

Снова открой Блокнот и напиши любую новую абракадабру. Сохрани в своей папке файл под именем Финиш.

твоя папка→Финиш→MAX→проверка→удалить папку

Открой MAX кнопкой сайта. В MAX открой «Избранное», прикрепи Финиш и отправь. Убедись, что файл появился в чате. После этого удали свою папку с Рабочего стола обычным способом.
