Урок 1 · 40 минут

Посчитал → записал → нашёл → удалил

Первый урок — не про «где какая кнопка». Ты сразу пройдёшь настоящий рабочий цикл Windows: проверишь себя Калькулятором, создашь свою папку, сохранишь файл, найдёшь его поиском, разберёшься с Корзиной и отправишь итог себе через MAX.

Уже всё это умею · FAST ≈ 7 минут

Пройди цепочку без подсказок

Создай на Рабочем столе папку со своим именем. В Блокноте сохрани в неё файл Проба с любой абракадаброй. Закрой Блокнот. Найди свою папку не глазами, а поиском в Проводнике. Удали «Проба», найди его в Корзине и удали окончательно. Затем создай в папке новый файл Финиш, отправь его себе через MAX, убедись, что он появился в MAX, и только после этого удали папку обычным способом.

Справился → FAST CHALLENGEЕсть пробел → обычный маршрут

FAST проверяет действие, а не знание терминов. Никакого штрафа за переход в обычный маршрут.

1. Сначала голова, потом Калькулятор

Попробуй посчитать в уме:
47 × 99
Не открывай Калькулятор сразу.
1
99 — это почти 100.
Сначала считаем 47 × 100 = 4700.
2
Теперь надо вычесть 47. Но 50 вычитать проще:
4700 − 50 = 4650.
3
Мы вычли не 47, а 50 — то есть лишние 3. Возвращаем их:
4650 + 3 = 4653.
4
Ответ: 4653. Теперь Калькулятор нужен не для размышления, а для проверки.
Твоя попытка: посчитай в уме 68 × 99 тем же способом. Только после этого нажми клавишу Windows, напечатай «Калькулятор», открой программу и проверь результат.

2. Создай свою рабочую папку

На Рабочем столе создай новую папку и назови её своим именем. Если в классе два одинаковых имени — добавьте первую букву фамилии.

Способ: правый клик по свободному месту Рабочего стола → создать папку → ввести имя → Enter.
Дмитрий
Смысл: папка создаётся учеником сейчас. Никакой заранее подготовленной «Курс ИИ → L01» нет.
7:00–12:00

3. Напиши абракадабру и просто сохрани

Через поиск Windows открой Блокнот. Напиши:

Абракадабра. Синий ёжик едет на лифте на Луну.

Теперь нажми Сохранить или Ctrl+S. Документ новый, поэтому Блокнот сам спросит, куда его сохранить. Выбери свою папку на Рабочем столе. В имени файла напиши просто Проба и нажми «Сохранить».

Расширение не дописываем. В обычной настройке Windows расширения часто скрыты, и для этого урока они вообще не нужны. В имени пишем только Проба.

Рабочий стол → Дмитрий

Первое сохранение нового документа само открывает выбор места и имени.

12:00–19:00

4. Найди свою папку не глазами

Закрой Блокнот и не ищи папку перебором значков на Рабочем столе.

Другой способ: открой Проводник Win+E → выбери Рабочий стол → в поле поиска напечатай имя своей папки. Открой найденную папку и убедись, что внутри лежит Проба.

19:00–25:00

5. Удали «Проба» и проверь Корзину

В своей папке выбери только файл Проба и удали его обычным способом. Затем открой Корзину и найди там именно Проба.

Перед окончательным удалением: преподавателю видно имя выбранного файла. Только учебный Проба. Не использовать Shift+Delete, не очищать всю Корзину.
Корзина

Проба

Сначала увидел правильный учебный файл → потом удалил его из Корзины окончательно.

Проверка понимания: после обычного удаления файл исчез из твоей папки, но ещё существует в Корзине. После удаления из Корзины учебный файл исчезает окончательно.
25:00–31:00

6. Финал: создай результат и отправь его себе через MAX

Снова открой Блокнот и напиши любую новую абракадабру. Сохрани в своей папке файл под именем Финиш.

твоя папка→Финиш→MAX→проверка→удалить папку

Теперь открой MAX кнопкой сайта, перейди в свой чат / «Избранное», прикрепи Финиш и отправь себе. Убедись, что файл появился в MAX. Только после этого удали свою папку с Рабочего стола обычным способом.

FAST CHALLENGE

Создай новую папку с другим названием, например Тест-L01. В ней создай файл Секретный-ёж с одной строкой абракадабры. Закрой всё. Найди папку поиском в Проводнике, отправь файл себе через MAX, проверь получение и удали папку. Без подсказок и без ИИ.

Важно: «Секретный-ёж» — только название учебного файла. Никаких настоящих секретов, паролей или личных документов.

Что ты реально тренируешь

Найти программу через поиск Windows; создать свою папку; сохранить новый текстовый файл в нужное место; найти папку и файл поиском; понять Корзину; передать итоговый файл через MAX.

Не учим «активное окно». Не требуем видеть расширение файла. Не используем заранее подготовленную папку.
