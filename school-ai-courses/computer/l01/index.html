Уже умеешь? Не трать урок на повторение

Без ИИ, подсказок и инструкции преподавателя:

  1. открой через Windows Параметры, Калькулятор и Блокнот;
  2. переключись Блокнот → Параметры → Калькулятор → Блокнот;
  3. закрой только Калькулятор.

3. Не ищи окно мышкой — переключайся

Когда открыто несколько программ, используй Alt + Tab. Держи Alt и нажимай Tab, пока не выберешь нужное окно.

4. Окно «пропало»

Сначала попробуй найти его сам: посмотри на панель задач и вспомни Alt + Tab. Только если не получилось — подключай ИИ.

5. Финальная задача — без пошаговой инструкции

Доказательство, что навык освоен

1. Закрой все три учебных приложения.

2. Самостоятельно открой через поиск Параметры, Калькулятор и Блокнот.

3. Переключись: Блокнот → Параметры → Калькулятор → Блокнот.

4. Закрой только Калькулятор. Два остальных окна должны остаться открыты.

Преподаватель не подсказывает маршрут. Если ты выполнил всё самостоятельно — это уже не просто «знаю кнопку», а могу решить задачу.

31:00–40:00

FAST CHALLENGE · перенеси навык

Без инструкции: открой Проводник, Paint и Microsoft Edge. Сделай Edge активным, затем переключись в Проводник, потом в Paint. После этого «потеряй» Edge за другими окнами и верни его без повторного запуска.

Если справился — можешь не проходить объясняющие части L01. Покажи результат преподавателю и переходи к следующему уроку.
