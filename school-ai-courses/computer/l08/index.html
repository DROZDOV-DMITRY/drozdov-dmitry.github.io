Скачать файл — только половина задачи. Нужно найти его в браузере, затем как настоящий файл в Проводнике и определить его тип.

Скачай и найди двумя маршрутами

1. Разминка + скачай учебный файл

4–6 минут печати: набери без копирования фразу «Я знаю, где искать скачанный файл: сначала браузер, потом Проводник». Следи за точностью.

Если L08-START.txt уже скачан во время FAST_GATE, используй эту копию. Иначе:

Браузер может сохранить файл автоматически или спросить место. Не запоминай «магическую папку»: определяй фактическое место сохранения. Если браузер блокирует или помечает файл как опасный, не отключай защиту и не обходи предупреждение — остановись и сообщи преподавателю.

0:00–8:00

2. Маршрут №1: найди загрузку в браузере

Открой список загрузок своего браузера и найди L08-START.txt. На Windows в актуальных Yandex Browser и Microsoft Edge это можно сделать сочетанием Ctrl+J. В другом браузере используй пункт Загрузки / Downloads в меню. Точная кнопка может отличаться — оценивается результат.

Проверь: имя совпадает с L08-START.txt. Если браузер показывает путь или команду открытия расположения файла, запомни это для следующего шага.
8:00–14:00

3. Маршрут №2: найди тот же файл в Проводнике

Открой Проводник. Если браузер использовал стандартную папку, начни с «Загрузки / Downloads». Если ты выбрал другое место — открой именно его. Найди L08-START.txt.

Если список большой: находясь в предполагаемой папке, используй уже знакомый поиск по имени L08-START.txt.

4. Определи тип файла, не угадывая по иконке

Минимальный способ: выдели L08-START.txt → правый клик → Свойства / Properties → найди строку «Тип файла / Type of file».

Правый клик здесь — вспомогательное действие для получения evidence; отдельное освоение контекстного меню не оценивается в L08.

Для L08 достаточно назвать тип так, как его показывает Windows.

Видимое расширение может быть подсказкой, но FILE-018 здесь не является условием прохождения.
