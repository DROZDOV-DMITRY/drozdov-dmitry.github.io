Урок 18. Автоматизируй папку: первые команды CMD

Создай собственную мини-автоматизацию, которая воспроизводимо готовит учебный каталог и журнал, не затрагивая системные и чужие файлы.

40–60 минут · Windows 7 и новее · без прав администратора

До подсказок · самостоятельная попытка

Сначала попробуй сам

Сначала сам опиши алгоритм из трёх операций, который подготовит папку нового проекта повторно без ошибок. Объясни, что произойдёт при втором запуске.

Поле — это только самоотчёт, а не автоматическое доказательство навыка.

Задача и рабочие условия

Только разрешённая командная строка и Блокнот; вся работа ограничена собственной папкой в %TEMP%. Сценарии чужого происхождения не запускай.

Стоп-условия. Нельзя выполнять скачанные скрипты, команды удаления, изменения реестра, прав доступа, системных директорий или политики запуска. Действия строго внутри собственного %TEMP%.

Если интерфейс отличается или операция запрещена — не обходи ограничение. Уточни фактический экран и версию Windows, попроси одно действие у ИИ или педагога, не раскрывая персональные сведения.

1

Уточни безопасные границы

Определи единственный каталог опыта %TEMP%\S14_L18_LAB и правила: никаких удалений, перемещения системных файлов, сети или повышения прав.

Что должно быть видно: Путь явно ограничен временным каталогом текущего пользователя.
Нужна подсказка? Разверни после своей попытки

В командной строке echo %TEMP% показывает путь временного каталога. Не копируй его целиком в публичный чат.

2

Протестируй команды по одной

В разрешённой консоли создай папку, вложенную папку Черновики и пустой текстовый журнал. Проверь их через dir и Блокнот.

Что должно быть видно: Структура действительно появилась и не затронула другие каталоги.
Нужна подсказка? Разверни после своей попытки

Начни с echo и md; строку для журнала можно создать через echo Тест > «полный_путь\журнал.txt». Угловые символы перенаправления применяй только к своему файлу.

3

Собери повторяемый .cmd

В Блокноте создай учебный сценарий с @echo off, set для переменной LAB, if not exist для создания папок и записью состояния в журнал. Сначала внимательно прочитай его перед запуском.

Что должно быть видно: Команды читаемы, каждый путь находится внутри LAB.
Нужна подсказка? Разверни после своей попытки

Пример БЕЗОПАСНОГО сценария (строго внутри собственной временной папки):

@echo off
set "LAB=%TEMP%\S14_L18_LAB"
if not exist "%LAB%" md "%LAB%"
if not exist "%LAB%\Drafts" md "%LAB%\Drafts"
echo Test run>>"%LAB%\log.txt"
dir "%LAB%"

Сначала прочитай каждую строку и объясни её действие. Выполняй лишь при разрешении педагога.

4

Проведи два запуска

Выполни свой учебный скрипт дважды (только если политика школы разрешает локальные сценарии). Сравни структуру и убедись, что при втором запуске не потерялись созданные ранее файлы.

Что должно быть видно: Повторный запуск идемпотентен по папкам; журнал может добавлять новую запись.
Нужна подсказка? Разверни после своей попытки

Если запуск .cmd запрещён, не пытайся обходить политику: покажи текст алгоритма и выполни команды по одной в учебной консоли, если это разрешено.

5

Проверь лог и объясни ошибки

Намеренно укажи неверное ИМЯ вложенной учебной папки в копии сценария и обнаружь расхождение в структуре. Исправь свою копию и снова проверь.

Что должно быть видно: Ошибка воспроизведена и исправлена без удаления нужных данных.
Нужна подсказка? Разверни после своей попытки

Не используй del, rd /s, format, reg, powershell -ExecutionPolicy или администраторские команды. Очистка своей лаборатории — только вручную и после проверки с педагогом.

Финальное испытание · самостоятельно

Проверь перенос навыка

Создай новый сценарий для отдельной учебной папки L18_PROJECT_B: две вложенные папки и журнал; два запуска не должны повреждать результат. Покажи исходник и структуру.

Необязательное исследование: Добавь в журнал дату/время запуска, контроль существования нужных файлов и сообщение об ошибке, если путь недоступен. Проверь без удаления.

Реальное подтверждение: Читаемый исходник, две проверки запуска и объяснение границ воздействия.

Что делать при сбое

Политика запретила CMD/.cmd: подготовь алгоритм на бумаге или в Блокноте, продемонстрируй создание папок через Проводник, честно отметь, что выполнение скрипта не проверено.

После работы: оставь компьютер в прежнем состоянии, сохраняй только нужные свои учебные файлы и закрой личные аккаунты, если открывал.

Зафиксируй факты, не оценку себе
