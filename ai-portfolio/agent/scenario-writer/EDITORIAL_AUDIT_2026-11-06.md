# Scenario Writer Space — редакционная проверка

**Релиз страницы:** v1.0.0 · 06.11.2026  
**Материал:** пользовательский `ScenarioWriter_полное описание функций.html`, в исходнике указано Scenario Writer Space v2.1.  
**Метод:** глубокая переработка и фактологическая редактура по правилам W.R.I.T.E. v2.0 (WRITE-04, WRITE-07, WRITE-09).  
**Результат:** `/ai-portfolio/agent/scenario-writer/` и `/ai-portfolio/agent/scenario-writer/capabilities/`.

## Сохранённые смысловые блоки
1. Основной функционал, две версии (режиссёрская и техническая).
2. Три режима детализации, элементы screenplay, камера, свет, персонажи, действие, диалоги, VFX, звук, титры и B-roll.
3. Платформы, storytelling/CTA и гибридный AI+physical production.
4. Контроль качества, MUSE как авторская структура параметров, выходные данные и ограничения.

## Коррекции фактов и чрезмерных обещаний

| Исходный тезис | Решение / обоснование |
|---|---|
| «Timing до миллисекунд» | Тайм-код — плановый ориентир; точная синхронизация требует фактической дорожки, fps и монтажа. |
| «БАЗОВЫЙ 2–3 часа, ПОЛНЫЙ 6–10, ПРОФЕССИОНАЛЬНЫЙ 1–2»; затем «ПРОФЕССИОНАЛЬНЫЙ 10+ часов» | Противоречащие числа удалены; объём и сроки зависят от проекта. |
| «ПРОФЕССИОНАЛЬНЫЙ — 2–3 страницы», а позднее «70–100+ пунктов» | Третий режим назван производственным обзором: задача не в самом длинном тексте, а в ключевых решениях. |
| «Всегда HTML + PDF» | Разведён содержательный сценарный результат и доступность экспорта в конкретной среде. |
| «10% физический / 90% AI, ролик за один день» | Обозначено как частный пример проекта Titre, без универсального обещания. |
| «MUSE гарантирует одинаковое понимание без неточностей» | Описано как внутренний шаблон; никакие поля не гарантируют интерпретацию. |
| «99% делают неправильно» | Убрано как неподтверждённая статистика. |
| Фиксированные пределы роликов/стандартные Hook и CTA по платформам | Заменены ориентиром на актуальные правила площадки и цель формата. |
| Некорректное описание FPV-пилота и сил G | Переработано в наблюдаемую сцену пролёта дрона с проверкой безопасности/разрешений. |
| «PRODUCTION», «мультиплатформа» как неподтверждённые гарантии | Не переносятся как доказанный статус текущей реализации. |

## Сверка отраслевых терминов
Базовые элементы сценария (Scene Heading, Action, Character, Dialogue и Parenthetical) сопоставлены с [официальной справкой Final Draft Writer](https://kb.finaldraft.com/hc/en-us/articles/44713357935764-I-am-brand-new-to-Final-Draft-What-are-the-basics-of-writing-a-script-in-Final-Draft-Writer).

## Техническая публикация

- Веб-страницы имеют собственные canonical URL и отдельную мобильную CSS-сетку.
- `Scenario Writer Space` имеет публичную страницу ассистента со ссылкой на полное описание.
- Страница `/ai-portfolio/project/film/` содержит ссылки на ассистента и описание.
- Сценарий публикации `.github/workflows/publish-ai-portfolio.yml` защищает страницы нового ассистента и страницу film от перезаписи pinned источником.
- Не изменялись настройки возможного отдельного кастомного GPT в ChatGPT: он не идентифицирован как редактируемый объект доступных коннекторов.

## Ограничения проверки
Фактические возможности текущего исполняемого ассистента (вывод PDF, стабильность обработки длинных проектов, совместимость со Storyboard Generator) не доказаны исходным HTML. Их текст описывает как предполагаемый рабочий процесс, а не результат испытаний. Данные из пользовательского источника не удалены.
